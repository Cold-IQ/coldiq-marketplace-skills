# Copy Rules

## Core limits

- Draft two or three emails.
- Default to 75 to 90 words per email.
- Keep sentences under 20 words.
- Use one clear idea and one CTA per email.
- Keep subjects at three to five words.
- Use plain punctuation. Never use the U+2014 em dash character.
- Do not suggest open or click tracking.
- Use Markdown unless the user asks for a supported file format.

Longer copy is acceptable only when the user asks for proof-heavy writing and provides a source for
every proof point. Remove a claim when its source is missing or unclear. Treat approved facts as a
closed claim set. Do not infer a product benefit, reduction, improvement, or causal outcome from a
capability. A possibility label does not make an unsupported product outcome safe.

When a brief supplies only an artifact name, offer it by that exact name. Do not invent what the
artifact contains, covers, helps with, or changes.

## Language

Prefer common words, active voice, and direct verbs. Explain technical terms or remove them. For a
non-native reader, avoid idioms, cultural references, nested clauses, and ambiguous pronouns.

Write about the prospect before the sender. State the likely problem as a possibility unless verified.
Do not claim private knowledge. Do not use false familiarity, false urgency, fake referrals, or
unsupported praise.

## Message anatomy

1. Relevance: identify the role, situation, or verified event.
2. Problem: name one operational difficulty.
3. Outcome: state what changes only when approved evidence supplies that outcome.
4. Proof: include one supported proof point when available.
5. CTA: ask for one low-effort action.

Each follow-up must add a useful angle. Do not repeat the first email with different words.

## Quality checks

- Every factual claim maps to a source.
- Every sentence supports relevance, value, proof, or the CTA.
- The recipient can understand the request on the first read.
- The CTA asks for only one action.
- Spintax, when requested for a sequence, does not change facts or meaning.
- Reply copy never contains spintax.
